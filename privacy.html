Learning Quest Privacy Policy

Last updated: November 1, 2026

Learning Quest is a learning game for children in Kindergarten through Grade 5. We do not collect, receive or sell any personal information, from children or from adults. The app has no accounts, ads, analytics, trackers or in-app purchases, and it has no chat or other way for a child to contact anyone.

What stays on the device

A parent enters a child's name or nickname, age, grade, levels, interests and support settings. As the child plays, the app saves answers, progress, feelings check-ins and rewards. All of this is stored only on the device. It is never sent to us or to anyone else.

Backup codes

A parent can copy a backup code from the parent dashboard to move progress to another device. The code contains the child's saved information. It stays wherever the parent chooses to put it, so please keep it private.

Read-aloud

Read-aloud uses the voices built into the device. The app does not use the microphone or camera.

The website

The browser version is hosted on GitHub Pages. GitHub may keep standard server logs, such as IP addresses, under its own privacy policy. The app installed from the App Store doesn't connect to our website.

Parents' choices

A parent can review or erase a child's information at any time in the parent dashboard. Deleting the app removes everything saved in it from that device.

Changes and contact

If this policy changes, we will update the date above. Questions are welcome at github.com/eezzz/learning-quest/issues.
